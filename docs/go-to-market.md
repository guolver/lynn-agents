# 市场推广与验证策略

本文档记录 Agent Hub 产品的市场验证和推广策略。

## 产品定位

- **核心价值**：帮助用户找到全球远程工作机会，并通过 AI 模拟面试提升面试成功率
- **目标用户**：
  - 寻找远程工作的开发者/求职者
  - 准备技术面试的人
  - 希望获得全球工作机会的人

## 2. 内容营销

### 内容类型与发布渠道

| 内容类型 | 示例 | 发布渠道 |
|---------|------|----------|
| 教程 | "如何准备海外远程面试" | 公众号、知乎 |
| 数据报告 | "2024 远程岗位薪资趋势" | 微博、即刻 |
| 工具对比 | "5 个找远程工作的平台对比" | 小红书 |
| 面试技巧 | "系统设计面试常见问题" | B站、YouTube |

### 内容规划

- **频率**：每周 1-2 篇
- **重点**：解决用户实际问题，自然引流到产品
- **形式**：图文为主，视频为辅

## 3. 快速验证方法

### 验证漏斗

```
Landing Page → 收集邮箱 → 观察转化率
                  ↓
            转化率 > 5% → 值得继续投入
            转化率 < 1% → 调整定位或功能
```

### 关键指标

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 落地页访问 → 注册 | > 5% | 产品吸引力 |
| 注册 → 活跃使用 | > 30% | 产品价值 |
| 用户留存（7日） | > 20% | 产品粘性 |
| NPS | > 30 | 用户推荐意愿 |

### 推荐工具

| 用途 | 工具 |
|------|------|
| 落地页 | 直接用首页，加邮箱收集表单 |
| 数据分析 | Umami（自托管）、Plausible、Google Analytics |
| 邮件营销 | Resend、Mailchimp |
| 用户反馈 | Canny、简单的 Google Form |

## 4. 冷启动策略

### 阶段一：找到前 100 个用户

1. **主动触达**
   - 在 LinkedIn 搜索 "looking for remote"
   - 即刻/Twitter 上关注远程工作话题的人
   - 直接私信，邀请免费试用

2. **社群运营**
   - 建微信群/Discord，聚集早期用户
   - 收集反馈，快速迭代
   - 让用户参与产品决策

3. **合作推广**
   - 联系远程工作相关的公众号/博主
   - 提供免费使用权换取曝光
   - 互推合作

### 阶段二：扩大规模

1. **内容沉淀**
   - 基于用户问题产出内容
   - SEO 优化，获取搜索流量

2. **口碑传播**
   - 邀请机制（邀请好友获得额外功能）
   - 用户案例展示

## 5. 付费推广（验证 PMF 后）

等免费渠道验证 PMF（Product-Market Fit）后再考虑：

| 渠道 | 适用场景 | 预算建议 |
|------|----------|----------|
| Google Ads | 关键词：remote jobs、模拟面试 | 500-2000 元/月起 |
| 小红书投流 | 面试技巧、求职类内容 | 300-1000 元/月起 |
| 抖音投流 | 短视频引流 | 500-2000 元/月起 |
| 播客赞助 | 技术/职场类播客 | 按单次合作 |

### PMF 信号

- 用户主动推荐给朋友
- 用户愿意付费
- 用户留存率稳定
- 用户反馈中出现 "离不开" 类表述

## 8. 注意事项

1. **避免过度推广**：在社区发帖要有价值，不要纯广告
2. **快速响应反馈**：早期用户反馈是最宝贵的
3. **数据驱动决策**：用数据验证假设，不要凭感觉
4. **保持迭代节奏**：每周至少一次产品更新
5. **记录学习**：把每次推广的效果记录下来，不断优化
